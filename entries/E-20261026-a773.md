`-I` implies `-E` (ignore PYTHON* variables) and `-P` (do not add the script or current folder to sys.path). Setting `PYTHONIOENCODING=utf-8` therefore has no effect under `-I`; `-X` options still work.

Side effect: `python -I -m unittest tests.test_x` cannot import a module from the current folder.
