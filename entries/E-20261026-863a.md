When stdout is a console, Python writes UTF-8; when it is a pipe or file, it uses the locale encoding. Printing a character outside that code page then raises `UnicodeEncodeError`.

Measured on Python 3.13.6: redirected `sys.stdout.encoding` was `cp950` plain, `cp950` with `-I`, `cp950` with `PYTHONIOENCODING=utf-8 python -I`, and `utf-8` with `-X utf8 -I`.
